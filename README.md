# フォーエバーヤング · Codex 桌宠

青春永驻 / Forever Young，以 Cygames 官方决胜服为依据的 Q 版形象。

九组动作：待机、左右跑动、挥手、跳跃、失落、等待回应、专注工作、审阅。安装包 ZIP 包含完整成品；图集、预览、官方原始角色语音与来源说明也将在仓库中提供。

安装：将 `package/forever-young` 放入 `${CODEX_HOME}/pets/`，随后在应用的设置 → Pets 中点击 Refresh 并选择「フォーエバーヤング」。

语音取自 Cygames 官方角色页，CV 海弓シュリ，未剪辑、未合成。桌宠配置没有已确认的自动播放音频接口。详见 `CREDITS.md`。
